# Md. Naim Ferdous — Portfolio v1

A responsive personal portfolio for **Md. Naim Ferdous**, focused on cybersecurity, software development, SQA and security research.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive dark UI
- `script.js` — mobile navigation and dynamic year
- `assets/` — place profile/project images here

## Run locally

Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a repository for the portfolio.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `assets/`.
3. In GitHub, open **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and wait for the deployment.
